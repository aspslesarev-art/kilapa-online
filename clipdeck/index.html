Как начать

1
Установи

Открой Clipdeck.dmg и перетащи Clipdeck в «Программы». Первый запуск — правый клик по иконке → «Открыть» (приложение пока без подписи Apple, это нормально).

2
Разреши «Универсальный доступ»

При запуске macOS попросит доступ — нажми «Разрешить». Только с этим разрешением Clipdeck может вставлять выбранное прямо туда, где курсор — он нажимает ⌘V за тебя. Без него приложение лишь копирует в буфер. Никаких других данных доступ не даёт.

3
Нажми ⌥⌘C

Откроется панель с историей и заготовками. Клик по записи — вставка, наведение — иконка «копировать». Готово.

Попробуй прямо сейчас

Вызов ⌥⌘C, поиск и вставка в любое приложение.
