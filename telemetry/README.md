# Kelappa telemetry — кто установил и кто пользуется

Каждое приложение раз в день говорит одну фразу: «я живо, вот моя версия».
Из этих фраз считается, сколько копий установлено и сколько из них реально
работают сегодня, за неделю и за месяц.

```
приложение → POST JSON → Apps Script (/exec) → лист «Usage»
                                     ↓
                       GET /exec?report=usage → kelappa.com/stats/
```

Приёмник — тот же, что у email-гейта: `apps-script/Code.gs`. Отдельной
инфраструктуры нет, платить не за что.

## Три события

| событие | когда | сколько раз |
|---|---|---|
| `install` | первый запуск на этой машине | один раз за установку |
| `launch` | запуск приложения | раз за запуск (два запуска в пределах 10 минут считаются одним) |
| `active` | приложение открыто в этот день | раз в сутки |

`install` даёт «сколько установили», `active` — «сколько ими реально
пользуются». Разница между ними и есть отвал.

## Что уходит наружу

| поле | пример | зачем |
|---|---|---|
| `app` | `Onit` | какое приложение |
| `event` | `active` | что случилось |
| `installId` | `9F2C…` (UUID) | случайный id **копии приложения**, создаётся при первом запуске |
| `version` | `1.0 (1)` | кто на какой версии сидит |
| `platform` | `macOS 15.3.1` / `web` | на чём работает |
| `locale` | `ru-RU` | язык системы |
| `ts` | ISO-8601 UTC | время по часам клиента (в листе есть и серверное) |

Ни почты, ни имени, ни содержимого работы. `installId` — это случайный UUID,
по нему нельзя узнать человека; он живёт в `UserDefaults` (Mac) или
`localStorage` (веб) и умирает вместе с приложением.

Эндпоинт открытый — кто угодно может послать в него выдуманную строку. Для
«сколько у меня пользователей» этого достаточно; если однажды понадобится
защита от накрутки, это уже другой разговор (подпись запроса или свой бэкенд).

## Добавить в macOS-приложение

1. Скопировать `KelappaTelemetry.swift` в исходники приложения.
2. Если имя бандла не совпадает с названием в статистике — задать его:
   `Telemetry.appName = "EN-RU Switcher"`.
3. Вызвать `Telemetry.start()` один раз, в `applicationDidFinishLaunching`.
4. Добавить в меню переключатель «Отправлять анонимную статистику»
   (`Telemetry.isEnabled`) — так это сделано в Onit.
5. Если приложение в песочнице (App Sandbox), нужен
   `com.apple.security.network.client` в entitlements. Без песочницы —
   ничего не нужно, hardened runtime сети не мешает.

Всё остальное — троттлинг, очередь при отсутствии сети, отказ от отправки —
уже внутри файла. Никаких зависимостей, один файл, Foundation.

## Добавить в веб-приложение

Один тег на любой странице:

```html
<script defer src="https://kelappa.com/telemetry/kelappa-usage.js"
        data-app="FloFi" data-version="1.4"></script>
```

`data-app` обязателен, если на домене больше одного приложения; без него
именем становится хост. Отключается пользователем через
`localStorage.kelappa_telemetry_off = '1'`.

## Где смотреть

`kelappa.com/stats/` — блок «Пользователи приложений»: установки, активные
сегодня / за 7 дней / за 30 дней, версии, когда приложение последний раз
подавало голос. Данные обновляются раз в 5 минут (кэш Apps Script);
`?nocache=1` у эндпоинта пересчитывает сразу.

Сырые строки — лист `Usage` в таблице [Kelappa leads](https://docs.google.com/spreadsheets/d/1keWRNoi1SiiNVG7CLP_UB1OeQWyxF1qmdfONbqG4HZ4/edit).

## После правки клиента

Файл `KelappaTelemetry.swift` — зеркало: его копии лежат внутри приложений
(`Sources/Onit/Telemetry/Telemetry.swift` в Onit и так далее). Поправил здесь —
перенеси в приложения, иначе они разъедутся.
